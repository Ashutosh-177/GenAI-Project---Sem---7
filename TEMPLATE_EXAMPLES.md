# Template Example Answers

Ready-to-copy example answers for all 12 drafting templates (`Draft a Document`
tab in the demo). Fields ending in `_brief` are AI-expanded — give them a real
sentence, not a placeholder (a too-short brief gets rejected by design; see
`Memory.md`'s scope-leak bug entry for why). Fields with a noted default can
be left blank.
